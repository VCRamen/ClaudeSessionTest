# 🎃 Halloween Siege（モック版）

ブラウザで動く TPS ウェーブサバイバルシューティングです。
ハロウィンの飾りつけをした夕暮れの商店街（十字路）で、Wave ごとに通りの先から押し寄せるモンスターを、物陰に隠れながら撃退します。

- 主人公は **VRM ファイル**をドラッグ＆ドロップ、またはファイル選択で読み込めます（読み込まない場合はマネキンで遊べます）。
- ファイルはブラウザ内だけで読み込み、サーバーへは送りません。

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # dist/ に静的ファイルを出力（GitHub Pages などにそのまま置けます）
```

## GitHub Pages で公開する

`.github/workflows/deploy-pages.yml` により、`main` ブランチに push されると自動でビルドして公開します。
初回だけ、GitHub のリポジトリ画面で **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

| 左クリック | 射撃 |
| 右クリック | エイム（スナイパーはスコープ。スコープ中はホイールで倍率変更） |
| Shift | ダッシュ |

## ステージ

ボスを倒すごとに次のステージへ進みます（仮の進行。5 Wave で 1 ステージ）。

| ステージ | Wave | 内容 |
| --- | --- | --- |
| 1. 商店街 | 1〜5 | ハロウィン飾りの夕暮れの商店街（下の「マップ」） |
| 2. ビル街 | 6〜10 | マンションと高層ビルが並ぶ大通り。北西・南東はオフィス街の裏通り、北東は噴水のある広場、南西は駐車場。路肩に車が停まり、工事中のコーンが置かれている。遠くに高層ビル群が見える |

- エンドレスでは 11 Wave 目から再び商店街に戻り、5 Wave ごとにステージが入れ替わります。
- 時間帯はステージごとに夕方から始まり、Wave が進むにつれて夜になります（ビル街は青い夕暮れ）。

## 高所の敵（ベランダ）

- Wave 2 以降、Wave の開始時にベランダなどの高所にパンプキンメイジが陣取り、上から火球を撃ってきます（商店街は 2 階の物干しベランダ、ビル街はマンションの 2〜3 階のガラス張りのベランダ）。数は Wave が進むと増え、ビル街では 1 体多くなります（最大 5 体）。
- 高所の敵はその場から動きません。ミニマップにピンク、Wave 開始時に画面中央まわりのピンクの円弧（▲ 高所）で方向を表示します。
- 倒すとドロップアイテムがベランダから真下の地面に落ちてきます（地面の光る輪が落ちる場所。着地するまでは拾えません）。

## マップ

- 十字の大通りと、その間の 4 つの区画からなる商店街。
  - 北西・南東：細い路地が入り組んだ区画（提灯と勝手口の並ぶ裏路地）
  - 北東：鳥居と社殿のある小さな神社の公園（生け垣・石灯籠・紅葉の木）
  - 南西：車の停まった駐車場（車が遮蔽物になる）
- 敵の出現口は各辺に 4 つ（大通りの突き当たり 2 か所と、路地・公園・駐車場の奥）。Wave ごとにどの辺から来るかが変わります。
- 遮蔽物：コンクリートのプランター、積まれたコンテナ、自動販売機、車、生け垣、建物の壁など。

## 壁への張り付き（カバー）

- 壁や遮蔽物の近くで **Q** を押すと張り付きます（画面下に案内が出ます）。もう一度 Q を押すか、壁から離れる方向へ移動すると解除。
- **低い遮蔽物**（プランター・車など）：遮蔽物に背をつけて深くしゃがみ、銃を体の前で斜めに構えます。**右クリック**（または左クリック）で立ち上がって撃てます。
- **高い壁**（建物・自販機など）：壁に背をつけ、銃を顔の横で上に向けて構えます。**A/D** で壁沿いに移動し、壁の端まで行くと右クリックで角から身を乗り出して撃てます。壁沿いに置かれた物で行き止まりになった場所では、壁から一歩出て撃ちます。
- 張り付くとカメラがキャラクターの前側へ回り、壁と身を乗り出す側を斜めに見る向きになります（マウスを動かせば自由に操作できます）。
- 隠れている間は撃てません（身を乗り出している間だけ撃てます）。
- 店・看板・提灯・ガーランド・空などはすべてコードで生成しているため、画像ファイルは使っていません。

## ゲーム仕様（現在の実装）

### 進行
- 全 10 Wave でクリア。クリア後は **エンドレス**で続けるかを選べます。
- 5 Wave ごとにボス「パンプキンキング」が出現（取り巻きのコウモリを召喚）。
- Wave が進むほど敵の数・体力・攻撃力が上がります。

### 武器
武器は 6 種類で、それぞれ性能の違う機種があります（全 17 機種）。拾うときやショップでは、威力・連射・装弾数・リロード・予備弾が「基礎値 + レベルによる強化値」の形で表示されます（例：威力 42 +16.8）。

| 種類 | 機種（出現 Wave） | 特徴 |
| --- | --- | --- |
| ハンドガン | ハンドガン（初期装備） | 予備弾無限（マガジンのリロードは必要） |
| | マシンピストル（1〜） | 片手で撃てるフルオート |
| | マグナム（3〜） | 一撃が重く 2 体貫通。6 発のみ |
| サブマシンガン | サブマシンガン（初期選択／1〜） | 扱いやすい標準 SMG |
| | ラピッド SMG（3〜） | 超高速連射。ブレが大きい |
| | ヘビー SMG（3〜） | 威力が高く連射は遅め |
| ショットガン | ポンプショットガン（初期選択／1〜） | 近距離で強力 |
| | ダブルバレル（3〜） | 2 連発の超火力。すぐ弾切れ |
| | オートショットガン（5〜） | 連射できるショットガン |
| ライフル | アサルトライフル（3〜） | 万能なフルオート |
| | バトルライフル（5〜） | 高威力・2 体貫通。装弾数少なめ |
| | バーストライフル（5〜） | 1 回で 3 発撃つ精密射撃 |
| スナイパー | スナイパーライフル（5〜） | 高威力・3 体貫通・スコープ |
| | マークスマンライフル（5〜） | 連射できる半自動。貫通なし |
| | 対物ライフル（7〜） | 超火力で 8 体貫通。3 発のみ |
| ランチャー | ロケットランチャー（7〜） | 直進して大爆発 |
| | グレネードランチャー（7〜） | 放物線を描く榴弾。物陰の敵も狙える |

- 敵の撃破や酒樽・ガスボンベの破壊で武器・回復・弾薬がドロップします。後半の Wave ほど強い武器や強化済みの武器が出やすくなります。
- 武器スロットは 4 つ。ドロップ武器に触れて約 0.7 秒たつと（案内のゲージが満タンになると）、1〜4 キーでそのスロットに登録できます。それまでは 1〜4 キーはふつうの武器切り替えです（通りすがりに誤って拾わないように）。元の武器はその場に落とします。
- スナイパー系はスコープの倍率をホイールで ×1.5〜×8 の間で切り替えられます（最初は ×2。最大はスナイパーライフル ×6、マークスマンライフル ×4、対物ライフル ×8）。倍率が高いほど視点の動きがゆっくりになります。
- **すでに持っている武器と同じ機種**のドロップは、金色に光るボーナスアイテムになります。触れるだけで拾い、その武器が 1 レベル強化され、弾薬が全回復します（最大レベルなら弾薬の全回復のみ）。

### 画面表示
- 左上のミニマップ：自分を中心に、向いている方向が上になるように回転します。道と建物、敵（赤。ボスはオレンジ、高所の敵はピンク。範囲外の敵は縁に表示）、アイテム（回復は緑、弾薬は黄、武器は出現段階の色、強化ボーナスは金）を表示します。

### 時間帯
- ステージの最初の Wave は夕暮れ。Wave が進むごとに日が暮れ、ボスの Wave では星と月の出た夜になります（Wave 開始時に数秒かけて移り変わります）。

### ショップ（Wave 終了時）
- 敵を倒すとお金が手に入ります。Wave クリア時にはボーナスもあります。
- 画面は左右に分かれています。左：武器の選択とプレイヤーの回復（HP 回復／全回復／最大 HP アップ）。右：選んだ武器の性能と、レベルアップ（Lv5 まで）・弾薬補充。

### 敵（ハロウィン系モンスター）
| 敵 | 行動 |
| --- | --- |
| パンプキンメイジ | 距離を取って火球を撃つ。頭（カボチャ）はダメージ 2 倍 |
| ゴースト | 浮遊し、ゆるく追尾する霊弾を撃つ |
| バット | 高速で接近して噛みつき、一度離れてから再び襲ってくる |
| パンプキンキング（ボス） | 5 方向に弾をばらまき、コウモリを召喚する |

- 敵は障害物を避けて移動し（グリッド上の経路探索）、プレイヤーが見えるときだけ撃ってきます。物陰に隠れれば攻撃をやり過ごせます。
- **襲来方向**：Wave ごとに主な襲来方向（東西南北のどれか 1 辺）が決まり、敵はその辺のゲートから現れます。Wave 開始時にオレンジの矢印で方向を表示します。Wave 4 以降は約 2 割が横の辺から回り込んできます。
- **持ち場と回り込み**：敵はプレイヤーが見えている間は持ち場から動かず、左右に少し揺れる程度です。見失うと 2〜3.5 秒待ってから回り込みますが、回り込めるのは同時に 1〜3 体（Wave が進むと増える）だけで、残りは正面で待機します。
- **被弾方向**：攻撃を受けた方向を画面中央まわりの赤い円弧で表示します。
- **しゃがみと遮蔽物**：しゃがむと当たり判定の高さが 1.0m になり、低い石壁（1.1m）や木箱（1.2m）の陰に完全に隠れられます。
- **コウモリ**：噛みついた後は 2〜3 秒離れてから、再び襲ってきます（ヒット＆アウェイ）。
- 赤い**プロパンガスボンベ**は、撃つと周囲を巻き込んで爆発します（連鎖あり）。

## モーションについて

モーションファイルは使わず、**コードで簡易モーションを生成**しています（歩き、しゃがみ、ジャンプ、銃の構え、エイムの上下、リロード（銃を上に向けて左手でマガジンを交換）、壁への張り付き）。
VRM の正規化ボーンを直接回しているため、VRM 0.x / 1.0 どちらのモデルでも同じように動きます。
今後 VRMA（VRM アニメーション）ファイルを読み込む仕組みに差し替えられるよう、見た目とモーションの処理は `src/Avatar.ts` にまとめてあります。
