# 🎃 Halloween Siege（モック版）

ブラウザで動く TPS ウェーブサバイバルシューティングです。
閉鎖された墓地のマップで、Wave ごとに襲ってくるハロウィンのモンスターを、物陰に隠れながら撃退します。

- 主人公は **VRM ファイル**をドラッグ＆ドロップ、またはファイル選択で読み込めます（読み込まない場合はマネキンで遊べます）。
- ファイルはブラウザ内だけで読み込み、サーバーへは送りません。

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # dist/ に静的ファイルを出力（GitHub Pages などにそのまま置けます）
```

## GitHub Pages で公開する

`.github/workflows/deploy-pages.yml` により、`main` ブランチに push されると自動でビルドして公開します。
初回だけ、GitHub のリポジトリ画面で **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

## ゲーム仕様（現在の実装）

### 進行
- 全 10 Wave でクリア。クリア後は **エンドレス**で続けるかを選べます。
- 5 Wave ごとにボス「パンプキンキング」が出現（取り巻きのコウモリを召喚）。
- Wave が進むほど敵の数・体力・攻撃力が上がります。

### 武器
| 武器 | 出現 | 特徴 |
| --- | --- | --- |
| ハンドガン | 初期装備 | 予備弾無限（マガジンのリロードは必要） |
| サブマシンガン | 初期サブ武器（選択）/ Wave 1〜 | 高連射 |
| ショットガン | 初期サブ武器（選択）/ Wave 1〜 | 近距離で高威力、距離で減衰 |
| アサルトライフル | Wave 3〜 | 中〜遠距離向けのフルオート |
| スナイパーライフル | Wave 5〜 | 高威力、敵を 3 体まで貫通、スコープ |
| ロケットランチャー | Wave 7〜 | 着弾で爆発（自爆ダメージあり） |

- 敵の撃破や樽の破壊で武器・回復・弾薬がドロップします。後半の Wave ほど強い武器や強化済みの武器が出やすくなります。
- 武器スロットは 4 つ。ドロップ武器の近くで 1〜4 キーを押すと、そのスロットに登録します。元の武器はその場に落とします。
- **すでに持っている武器と同じ種類**のドロップは、金色に光るボーナスアイテムになります。触れるだけで拾い、その武器が 1 レベル強化され、弾薬が全回復します（最大レベルなら弾薬の全回復のみ）。

### ショップ（Wave 終了時）
- 敵を倒すとお金が手に入ります。Wave クリア時にはボーナスもあります。
- 買えるもの：HP 回復／全回復／最大 HP アップ／武器強化（Lv5 まで）／弾薬補充

### 敵（ハロウィン系モンスター）
| 敵 | 行動 |
| --- | --- |
| パンプキンメイジ | 距離を取って火球を撃つ。頭（カボチャ）はダメージ 2 倍 |
| ゴースト | 浮遊し、ゆるく追尾する霊弾を撃つ |
| バット | 高速で接近して噛みつく |
| パンプキンキング（ボス） | 5 方向に弾をばらまき、コウモリを召喚する |

- 敵は障害物を避けて移動し（グリッド上の経路探索）、プレイヤーが見えるときだけ撃ってきます。物陰に隠れれば攻撃をやり過ごせます。
- 赤い**爆発樽**は、撃つと周囲を巻き込んで爆発します（連鎖あり）。

## モーションについて

モーションファイルは使わず、**コードで簡易モーションを生成**しています（歩き、しゃがみ、ジャンプ、銃の構え、エイムの上下、リロード）。
VRM の正規化ボーンを直接回しているため、VRM 0.x / 1.0 どちらのモデルでも同じように動きます。
今後 VRMA（VRM アニメーション）ファイルを読み込む仕組みに差し替えられるよう、見た目とモーションの処理は `src/Avatar.ts` にまとめてあります。

| `src/Level.ts` / `src/Barrel.ts` | マップ・遮蔽物・樽 |

| `src/Collision.ts` | 当たり判定・レイキャスト |
| `src/Projectiles.ts` | 敵の弾・ロケット弾 |
| `src/Pickups.ts` | ドロップアイテム |
| `src/Effects.ts` | パーティクル・弾道・爆発などの演出 |
| `src/Audio.ts` | 効果音（WebAudio で合成。音声ファイルは不要） |
| `src/Hud.ts` / `src/Shop.ts` | HUD とショップ画面 |
| `src/Config.ts` | 調整用の定数 |
